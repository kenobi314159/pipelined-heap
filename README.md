# Pipelined Heap

Pipelined Heap (Priority Queue) implementation for FPGA based on the following paper 

- Ioannou, A., & Katevenis, M. G. H. (2007). Pipelined HEAP (Priority Queue) management for advanced scheduling in High-Speed networks. IEEE/ACM Transactions on Networking, 15(2), 450–461. https://doi.org/10.1109/tnet.2007.892882
